# Sudhakavya Bodapati Venkata

Professional and scholarly portfolio covering DevOps engineering, cloud reliability, applied AI research, academic service, and speaking.

Website: https://sudhakavya.github.io/sudhakavyabodapati/

## Editing

Edit the static pages at the repository root. The GitHub Pages workflow uses Jekyll to publish the site, keep older page URLs working, and retain existing assets. The root HTML pages share a profile sidebar and navigation. The publications search and filters are in site.js.
